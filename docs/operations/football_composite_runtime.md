# Composite football runtime contract

The experimental version is `football_composite_v1`. Its code-owned capabilities
declare a required ready bundle, full reprojection, score-process survival, and
eligibility already included in all weeks
(`src/squadopt/prediction/football_capabilities.py:13`,
`src/squadopt/prediction/football_capabilities.py:43`).

The public receipt names six active heads in order: retained flag minutes, observed
competition workload, pooled FM unit rates, score-state survival, tactical
recipients and phase duties. Its asset inventory distinguishes the retained flag
result from compact fitted models. Every served player-week has a final-law hash,
fixture scope and matching appearance probability
(`src/squadopt/prediction/football_capabilities.py:17`,
`src/squadopt/prediction/football_composite_contract.py:52`).

The source codec accepts a concrete dataclass type supplied by application code.
It uses bounded canonical JSON and exact typed fields, refuses duplicate object
keys and preserves immutable tuples. Parameter artifacts retain their own family
readers. An integrity hash identifies bytes; it does not establish source rights
or authenticate a provider
(`src/squadopt/live/football_composite_codec.py:1`,
`src/squadopt/live/football_composite_codec.py:45`,
`src/squadopt/live/football_composite_codec.py:133`).

The news adapter reuses source-time and conflict decisions, then changes the
retained joint law and recomposes whole affected fixtures. It discards the scalar
participation updater's numeric result. Current statements with ambiguous fixture
scope are withheld. Independent agreeing absence sources are bound together into
one intervention; a full-match restriction does not supply a new appearance or
start estimate (`src/squadopt/application/football_composite_news.py:125`).

An unsupported minute restriction is withheld while verified absences still enter
recomposition. If the absence-only fixture cannot be composed, the forecast is
unavailable. Complete player-week identity and unchanged later weeks are checked
before binding results. The existing captured eligibility is not applied again
(`src/squadopt/application/football_composite_news.py:34`,
`src/squadopt/application/football_participation.py:442`,
`src/squadopt/application/football_participation.py:557`).

The public summary only claims a joint intervention and fixture recomputation when
a statement was applied. Withheld statements keep the retained baseline. Composite
future zeros do not receive the legacy warning about an unknown conditional basis
(`src/squadopt/application/football_participation.py:82`,
`src/squadopt/application/football_participation.py:613`).

Both the answer cache identity and the displayed decision revision bind the
reprojection version and fingerprint. A composite forecast missing that identity
cannot address an answer (`src/squadopt/platform/advice_switches.py:116`,
`src/squadopt/platform/advice_switches.py:176`).

This contract page does not record a live activation or a predictive-accuracy
result. Actual release and runtime verification remain separate completion steps.
